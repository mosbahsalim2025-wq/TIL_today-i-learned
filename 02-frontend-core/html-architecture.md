I am building the html structure for the Sousse Boxing Club web, 

b=> Bold
strong => Bold => Important Text
i=> Italic
em-> Emphasized
mark => Marked Text Or Highlighted Text
u=> Underline
small > Smaller text
del > Deleted Text
ins => Inserted Text
sub => Subscript
sup => Superscript
 
* `<h1>` to `<h6>` heading elements used to define the structure and organization of the content on a web page.
* `<b>` vs `<strong>` `<b>` changes font to bold. `<strong>` bolds the text and signals to the browsers and search engines that the text matters.
* `<i>` vs `em`  `<i>` text into italic front. `<em>` emphasizes the content for screen reader.
* `<mark>`  marked text or highlighted text
* `<del>` & `<ins>`  Displays a  line over deleted text (`<del>90dt</del>`) alongside fresh inserted text (`<ins>just 30dt</ins>`).

* `<a>` (anchor tag)  builds a link pathway to external web or internal page section IDs.
* `target="_blank"`  added to the <a> attribute to open the link in another page
###  Multimedia Infrastructure Nodes
* `<img>`, `<audio>`, `<video>`  present visual/audio streams pulling data from relative local folders (`images/`, `audio/`, `video/`).
